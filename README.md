# 橙食订 · 外卖 APP 原型

根据五张 UI 原型实现的移动端页面（React + Vite + TypeScript）。

## 页面

| 路由 | 页面 | 功能 |
|------|------|------|
| `/` | 首页 | Banner 轮播、分类、附近商家、限时特价、搜索排序 |
| `/shop/:id` | 商家详情 | 店铺信息、分类菜单、加购、购物车条 |
| `/product/:id` | 商品详情 | 规格选择、加入购物车 |
| `/cart` | 购物车 | 勾选、优惠券、费用明细、去结算 |
| `/checkout` | 确认订单 | 地址、备注、支付、提交成功 |
| `/login` | 登录注册 | 手机号 + 微信登录 |
| `/profile` | 个人中心 | 订单入口、功能菜单（未登录可浏览，引导登录） |
| `/orders` | 订单列表 | 状态筛选、订单详情摘要（需登录） |
| `/addresses` | 地址管理 | 新增/默认/选择模式 `?select=1`（需登录） |

## 登录说明（演示）

- 手机号：11 位以 `1` 开头
- 验证码：点击获取后自动填入 `123456`，或手动输入 4–6 位数字
- 支持微信一键登录（模拟）
- 登录态保存在 `localStorage`

## 特性（对标主流外卖 App）

- 全局购物车 Context + localStorage 持久化
- 加购合并相同规格、Tab 角标实时更新
- 满减、配送费减免、免配送门槛提示
- 空购物车 / 未选商品结算拦截
- 真实登录态、订单持久化、收货地址选择与结算联动
- `AppImage` 组件：外链图失败时自动显示本地 SVG 占位图

## 运行

需安装 [Node.js](https://nodejs.org/)（含 npm）：

```bash
cd C:\Users\86131\Projects\chengshi-ding
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5173`）。建议用开发者工具切换为 iPhone 尺寸预览。

